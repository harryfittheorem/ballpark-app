# Demo Screenshots

This directory holds fallback screenshots for live demos.

## When to capture

Capture screenshots after each major screen is polished and the Marcus Rivera demo scenario is seeded. Use these as a fallback if the live app is unavailable during a demo.

## Recommended coverage

| Screen | File name |
|---|---|

## How to capture

1. Run `node scripts/seed-demo-scenario.mjs` to load Marcus Rivera's data.
2. Open the app on a physical iPhone via Expo Go.
3. Use the iOS screenshot gesture (side button + volume up) for each screen.
4. AirDrop or sync to this directory and rename per the table above.
