The user wants a web portal option named "Training Playbook" under Operations (renamed from "Trainual"), replacing the client's use of Trainual with major training functionality inside this app. Intended users are staff, admins, and owners; coach learner access was recommended in the approved plan. The user approved building phase by phase within the same task.

**Why:** The client already uses Trainual, and preserving their existing information, artifacts, and videos during the transition is explicitly important.

**How to apply:** Require an inventory and migration verification before promising complete transfer or retiring Trainual. Distinguish preserved source archives from working, editable training content. Do not assume PDF exports contain videos or all content types.

The client uses Trainual Enterprise. The user will upload existing material manually through this app, or provide a Google Drive link where it is stored. Samples will be provided later.

**Why:** The user explicitly selected manual uploads or Google Drive as the migration source, rather than requiring a Trainual API connection.

**How to apply:** Prioritize direct uploads and preservation checks. Do not block module construction on Trainual API access, and do not represent a Drive link as copied, independently stored content.
